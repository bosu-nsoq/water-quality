# 💧 ระบบบันทึกคุณภาพน้ำ (Quality Water Check - PWA)

เว็บแอปพลิเคชันบันทึกและประเมินคุณภาพน้ำ (วัดค่า pH และ TDS) พร้อมระบบวิเคราะห์ผลแบบเรียลไทม์ ตารางประวัติย้อนหลัง และกราฟสถิติ พัฒนาด้วย Bootstrap 5, Chart.js, SweetAlert2 และรองรับการทำงานแบบ Progressive Web App (PWA) บน iOS / Android

---

## 📁 โครงสร้างโปรเจกต์

```text
water-quality-check/
├── index.html          # หน้าเว็บหลัก (Frontend รองรับ GitHub Pages 100%)
├── manifest.json       # ไฟล์การตั้งค่า PWA (ติดตั้งบนหน้าจอโฮมมือถือได้)
├── sw.js               # Service Worker สำหรับระบบแคชและออฟไลน์
├── icons/              # ไอคอนแอปพลิเคชัน (192x192, 512x512 และ SVG)
│   ├── icon-192.png
│   ├── icon-512.png
│   └── icon.svg
├── gas/
│   └── Code.gs         # สคริปต์ Google Apps Script (ทำหน้าที่เป็น Web API เชื่อม Google Sheets)
└── README.md           # คู่มือการติดตั้งและใช้งานระบบ
```

## 🚀 ขั้นตอนที่ 1: การนำโค้ดขึ้น GitHub และเปิดใช้งาน GitHub Pages

### 1.1 สร้าง Repository บน GitHub
1. ล็อกอินเข้า [GitHub](https://github.com) แล้วคลิก **"New repository"**
2. ตั้งชื่อ เช่น `water-quality-check`
3. เลือก **Public** แล้วกด **Create repository**

### 1.2 อัปโหลดโค้ดขึ้น GitHub
เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
git init
git add .
git commit -m "Initial commit: Water Quality Check PWA Web App"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/water-quality-check.git
git push -u origin main
```
*(แทนที่ `YOUR_USERNAME` ด้วยชื่อผู้ใช้ GitHub ของท่าน)*

### 1.3 เปิดใช้งาน GitHub Pages (โฮสต์เว็บฟรี)
1. ใน GitHub Repository ไปที่แท็บ **Settings**
2. เมนูด้านซ้ายเลือก **Pages**
3. หัวข้อ **Build and deployment > Branch**:
   - เลือก Branch เป็น `main`
   - โฟลเดอร์เลือกเป็น `/ (root)`
   - กดปุ่ม **Save**
4. รอประมาณ 1-2 นาที ท่านจะได้ URL เว็บไซต์ เช่น:  
   `https://YOUR_USERNAME.github.io/water-quality-check/`

## 📊 ขั้นตอนที่ 2: ติดตั้ง Google Apps Script เพื่อเชื่อมต่อ Google Sheets

ระบบนี้รองรับการทำงาน 2 โหมด:
- **โหมด Local:** ทดสอบใช้งานได้ทันท่วงที บันทึกข้อมูลลงในเครื่อง
- **โหมด Google Sheets:** ซิงค์ข้อมูลลงสเปรดชีตออนไลน์

### วิธีสร้าง Web API ใน Google Sheets:
1. เปิด [Google Sheets](https://sheets.new) สร้างสเปรดชีตใหม่ (เช่น ตั้งชื่อว่า `บันทึกคุณภาพน้ำ`)
2. ที่เมนูด้านบน คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดเดิมในโปรเจกต์ออก แล้วคัดลอกโค้ดจากไฟล์ `gas/Code.gs` ไปวางแทนที่ทั้งหมด
4. กดบันทึก (Ctrl + S)
5. **การเผยแพร่เป็น Web App (Deploy):**
   - คลิกปุ่มสีน้ำเงินมุมขวาบน **"ทำให้ใช้งานได้" (Deploy)** ➔ **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
   - ตรงไอคอนฟันเฟือง เลือกประเภท **"เว็บแอป" (Web app)**
   - คำอธิบาย: `v1.0`
   - เรียกใช้ในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ GitHub Pages ส่งข้อมูลมาบันทึกได้)*
   - กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
6. ให้สิทธิ์การเข้าถึง (Authorize access) เมื่อ Google ร้องขอ
7. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`

## 🔗 ขั้นตอนที่ 3: เชื่อมต่อ GitHub Pages เข้ากับ Google Sheets

สามารถเชื่อมต่อได้ง่ายๆ 2 วิธี:

### วิธีที่ 1 (สะดวกที่สุด - ไม่ต้องแก้โค้ด):
1. เปิดหน้าเว็บ GitHub Pages ของท่าน
2. คลิกปุ่ม **"⚙️ ตั้งค่าเชื่อมต่อ"** ที่มุมขวาบน
3. นำ URL เว็บแอปจากขั้นตอนที่ 2 มาวางแล้วกดบันทึก
4. สถานะจะเปลี่ยนเป็น **"เชื่อมต่อ Google Sheets"** พร้อมใช้งานทันที

### วิธีที่ 2 (กำหนดเป็นค่าเริ่มต้นในโค้ด):
เปิดไฟล์ `index.html` แล้วนำ URL ไปวางในบรรทัด:
```javascript
const DEFAULT_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
```
แล้ว `git commit` และ `git push` ขึ้น GitHub

## 📱 ขั้นตอนที่ 4: การติดตั้งเป็นแอปพลิเคชันบนมือถือ (PWA)

เว็บนี้ตั้งค่า PWA รองรับทั้ง iOS และ Android สามารถติดตั้งลงหน้าจอโฮมได้โดยไม่ต้องผ่าน Store:

- **iPhone / iPad (iOS):**
  1. เปิดเว็บด้วย **Safari**
  2. กดปุ่ม **แชร์ (Share)** (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น)
  3. เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
  4. แอปจะปรากฏบนหน้าจอหลัก เปิดใช้งานแบบเต็มจอ (Full Screen) ไร้แถบ URL เสมือนแอปแท้

- **Android:**
  1. เปิดเว็บด้วย **Chrome**
  2. แตะปุ่มเมนู (จุด 3 จุด) หรือแถบด้านล่าง
  3. เลือก **"ติดตั้งแอป" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก"**

## 🌟 ฟังก์ชันเด่นของระบบ
- ✅ **ตรรกะการแปลผลตรงตามเกณฑ์เดิม 100%:**
  - ค่า pH: ต่ำกว่า 6.5 (ควรปรับปรุง), 6.5-6.89 (พอใช้), 6.9-7.59 (ดี), 7.6-8.5 (พอใช้), มากกว่า 8.5 (ควรปรับปรุง)
  - ค่า TDS: ต่ำกว่า 500 (ดี), 500-1000 (พอใช้), มากกว่า 1000 (ควรปรับปรุง)
- ✅ **วันที่มาตรฐานไทย พ.ศ. (`dd/mm/yyyy`):** คลิกช่องวันที่เพื่อเปิดปฏิทินทันที ไม่มีไอคอนรก และบันทึก/แสดงผลเป็นปี พ.ศ. เสมอ
- ✅ **ดีไซน์กระจกแก้ว (Glassmorphism):** ใช้โทนสีสายน้ำและฟอนต์ `Mali` อ่านง่ายสบายตา
- ✅ **กราฟวิเคราะห์ย้อนหลัง:** เลือกดูข้อมูลทั้งหมด, สัปดาห์นี้, เดือนนี้ หรือปีนี้ได้ทันที
